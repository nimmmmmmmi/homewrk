# Отчёт по домашнему заданию 4. Применение модели акустической диагностики

Ноутбук: [`4_homework_model_diagnostics.ipynb`](4_homework_model_diagnostics.ipynb)

## Данные и модель

- `bearing_models_python.joblib` — сохранённый комплект: три `RandomForestRegressor`
  (`inner`, `outer`, `roller`), обученный `StandardScaler` на 54 признаках, а также параметры
  конвейера (`fs=10000`, окно 4000 отсчётов, перекрытие 0.75).
- `Bearing.mat` — эталонные сигналы `normal`, `inner`, `outer`, `roller`.
- `Подшипник.wav` — запись для диагностики.

Шкала 0–100 — учебная шкала коэффициентов смешивания, а не физический процент износа.

## Решения

| № | Задача | Решение |
|---|--------|---------|
| 1 | Загрузка комплекта | `joblib.load(DATA / "bearing_models_python.joblib")` |
| 2 | Извлечение частей | `bundle["models"]`, `bundle["scaler"]`, ... в одноимённые переменные |
| 3 | Нормализация | `scaler.transform(np.asarray(features, dtype=float).reshape(1, -1))` — без `fit` на новых данных |
| 4 | Диагностика сегмента | 54 признака → `normalize_features` → `models[key].predict(...)` для каждого ключа из `label_order` |
| 5 | Диагностика сигнала | `segment_signal` → `np.vstack` признаков окон → один `scaler.transform` → среднее прогнозов, `np.clip(0, 100)`, округление до 0.1 |
| 6 | Исправный подшипник | `diagnose_signal(normal, fs)` |
| 7 | Комбинированный сигнал | `normal + 0.08*(inner-normal) + 0.07*(outer-normal) + 0.12*(roller-normal)` |
| 8 | WAV-файл | `read_wav(...)` → `diagnose_signal(wav_signal, wav_fs)` |

Все восемь ячеек самопроверки показывают ✅.

## Результаты

| Сигнал | inner | outer | roller |
|--------|------:|------:|-------:|
| Один сегмент `normal` (задание 4) | 0.0 | 0.01 | 0.28 |
| Дефект `outer` целиком (задание 5) | 3.5 | 99.5 | 5.1 |
| Исправный подшипник `normal` (задание 6) | 0.2 | 0.1 | 0.4 |
| Смесь 0.08 / 0.07 / 0.12 (задание 7) | 4.6 | 3.0 | 9.2 |
| WAV-файл (задание 8) | 4.2 | 2.8 | 0.4 |

## Наблюдения

- Модель уверенно распознаёт дефект внешнего кольца (99.5) и почти не реагирует на исправный
  сигнал (значения около нуля).
- На смеси `normal` с малыми долями дефектов модель даёт оценки 4.6 / 3.0 / 9.2 — по порядку
  величины они сопоставимы с заданными долями (8 / 7 / 12), но не совпадают с ними точно:
  оценки получены из случайного леса, который обучался на других данных.
- Для `roller` оценка (9.2) ближе всего к «истинной» доле 12, для `inner` и `outer` модель
  занижает значения. Это хорошая иллюстрация того, что точные числа — это не измерение износа,
  а выход модели на учебной шкале.
- Функция `diagnose_signal` усредняет прогнозы по всем окнам, поэтому она устойчивее к
  локальным выбросам, чем `diagnose_segment`, которая смотрит на одно окно.
- WAV-файл показывает малые значения по всем трём категориям (≤ 4.2), то есть модель не
  находит выраженного дефекта в этой записи.

## Замечания

- При загрузке `joblib` появляется `InconsistentVersionWarning`: модель сохранена в
  scikit-learn 1.6.1, а в этом окружении стоит 1.9.1. Результаты при этом совпали с
  эталонными значениями самопроверки, но для надёжности лучше запускать с той же версией
  (`pip install scikit-learn==1.6.1`). Также загружать `joblib`/`pickle` можно только из
  доверенного источника.
- Использованный подход — применение готовой модели; обучение здесь не выполнялось.
