# Отчёт по домашнему заданию 2. EDA и Feature Engineering

Ноутбук: [`2_homework_eda_feature_engineering.ipynb`](2_homework_eda_feature_engineering.ipynb)

## Данные

`Сталелитейные_данные.csv` — 35 040 строк, шаг 15 минут, период 01.01.2018 – 31.12.2018,
8 числовых признаков: `Usage_kWh`, `Lagging/Leading_Current_Reactive_Power_kVarh`, `CO2_tCO2_`,
`Lagging/Leading_Current_Power_Factor`, `Temperature_C`, `Humidity_Pct`.

## Решения

| № | Задача | Решение |
|---|--------|---------|
| 1 | Временной диапазон | `pd.to_datetime(df["date"], format="%d/%m/%Y %H:%M")`, затем `.min()` / `.max()` |
| 2 | Описательная статистика | `df[NUMERIC].describe().T` |
| 3 | Статистика по сезонам | `df["DateTime"].dt.month.map(season_by_month)`, затем `groupby("Season")` с `mean`/`std` |
| 4 | Уровни загрузки | `df["Usage_kWh"].quantile([0.33, 0.67])` → `pd.cut` на 3 категории → `value_counts(sort=False)` |
| 5 | PCA | `StandardScaler().fit_transform(df[NUMERIC])` → `PCA(n_components=2).fit_transform(...)` |
| 6 | KMeans | `KMeans(n_clusters=3, random_state=42, n_init=20).fit_predict(X_scaled)` |
| 7 | Спектр (FFT) | первые 4096 значений `Usage_kWh`, вычесть среднее, `np.fft.rfft`, взять `np.abs` |

Все семь ячеек самопроверки показывают ✅.

## Наблюдения

- Среднее потребление `Usage_kWh` ≈ 27.39 кВт·ч, максимум температуры 37.4 °C — совпадает с
  домашним заданием 1, так как данные те же, только дополненные `Temperature_C`/`Humidity_Pct`.
- По сезонам среднее потребление различается не сильно (26.2–32.8 кВт·ч), но заметнее разброс
  (`std_usage`): зимой он самый большой (32.08), осенью — немного меньше.
- Деление на 3 уровня загрузки по процентилям даёт почти равные по размеру группы
  (11 634 / 11 851 / 11 555 наблюдений) — так и ожидается при разбиении по терцилям.
- Кластеризация KMeans на 8 стандартизированных признаках даёт неравные по размеру кластеры
  (14 499 / 7 677 / 12 864), то есть один из режимов работы предприятия встречается заметно реже
  остальных.
- В спектре `Usage_kWh` за первые 4096 отсчётов (~42.7 суток) видны выраженные пики на частоте
  1 цикл/сутки (суточная цикличность нагрузки) и около 1/7 цикла/сутки (недельная цикличность,
  рабочие/выходные дни) — это видно на графике спектра в ноутбуке.

## Выводы

Данные прошли полный цикл EDA: временной охват и описательная статистика проверены,
добавлена сезонность и категоризация по уровню нагрузки. Понижение размерности (PCA) и
кластеризация (KMeans) показывают, что в данных есть устойчивые группы режимов работы,
а частотный анализ (FFT) подтверждает ожидаемую суточную и недельную периодичность
энергопотребления.
