# Отчёт по домашнему заданию 3. Акустические сигналы и модели

Ноутбук: [`3_homework_bearing_diagnostics.ipynb`](3_homework_bearing_diagnostics.ipynb)

## Данные

`Bearing.mat` — четыре акустических сигнала подшипника по 120 000 отсчётов каждый
(`normal`, `roller`, `inner`, `outer`), частота дискретизации 10 кГц.

## Решения

| № | Задача | Решение |
|---|--------|---------|
| 1 | Загрузка `.mat` | `loadmat(DATA / "Bearing.mat")` |
| 2 | Векторы сигналов | `bearing[key].ravel()` для `normal`, `roller`, `inner`, `outer` |
| 3 | Окна с перекрытием | `step = int(length * (1 - overlap))`, список срезов по `range(0, len-length+1, step)`, `np.stack` |
| 4 | Синтетические смеси | `normal + mc * (defect - normal)`, признак — RMS после вычитания среднего **(включая базовый пример `normal`)** |
| 5 | 14 признаков окна | RMS, доминирующая частота (по `rfft`/`rfftfreq` без последней точки Найквиста), 10 энергий частотных полос по 500 Гц, доля пересечений нуля, отношение 75-го к 25-му процентилю |
| 6 | Нормализация | `(X - mean) / std`, `ddof=1`, защита от деления на ~0 |
| 7 | Три случайных леса | `RandomForestRegressor`: кольца — 400 деревьев/глубина 35, ролик — 600 деревьев/глубина 50, `random_state=42/43/44` |

Все семь ячеек самопроверки показывают ✅.

## Пойманная ошибка

В задании 4 условие требует RMS **после вычитания среднего** для всех 37 примеров,
включая нулевой (чистый `normal`). При первой попытке я посчитал RMS нулевого примера
без центрирования, из-за чего `X[0, 0]` не совпадал с ожидаемым `0.0726744486205`
(разница — пятый знак после запятой: `0.07375...` вместо `0.07267...`). Исправлено
на `rms(normal - normal.mean())`, после чего проверка прошла.

## Наблюдения

- Окна с перекрытием 75% дают 117 окон по 4000 отсчётов на каждый сигнал; соседние окна
  пересекаются на 3000 из 4000 отсчётов, поэтому визуально почти совпадают — это нужно
  учитывать, чтобы не получить data leakage между train/test при случайном разбиении окон.
- В 14 признаках окна `normal` доминирующая частота и распределение энергии по полосам
  дают базовую (здоровую) спектральную картину, с которой в семинаре сравнивались дефектные
  образцы.
- Задание 4 — учебная линейная интерполяция «mixing coefficients», а не реальные измерения
  износа: это прямо оговорено в условии и не должно восприниматься как шкала фактической
  деградации подшипника.
- Два «кольцевых» леса (`inner`, `outer`) настроены одинаково (400 деревьев, глубина 35),
  лес для `roller` — чуть мощнее (600 деревьев, глубина 50), видимо из-за более шумного
  сигнала ролика.

## Выводы

Собран полный конвейер от сырого `.mat`-файла до объектов моделей: загрузка сигналов,
сегментация окнами с перекрытием, построение синтетических смесей для обучающей выборки,
расчёт частотных и статистических признаков, нормализация и создание трёх
`RandomForestRegressor`. Обучение (`.fit`) в задании не требовалось — все семь шагов
были только про корректную форму данных и инициализацию моделей.
